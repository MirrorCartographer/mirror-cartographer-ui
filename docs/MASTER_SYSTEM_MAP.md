# Mirror Cartographer Working Machine — Master System Map

Status: active source of truth.

Purpose: turn conversation architecture into a durable repo-based machine.

The machine has seven workstreams:

1. Portal UI: the public/private interface people can use.
2. ARC Engine: offline reasoning, benchmark harnesses, solver experiments, and proof logs.
3. Proof Protocol: claim registers, earned-stop standards, benchmark evidence rules, and wrongness audits.
4. Delegated Action Protocol: safe authorized-assistant design for accounts, submissions, approvals, logs, and boundaries.
5. Opportunity Engine: competitions, prizes, bug bounties, grants, research programs, and submission packets.
6. Accessibility Layer: voice-reader-readable outputs, non-boxed critical instructions, and artifact summaries.
7. Reports and Submissions: benchmark results, paper drafts, bounty report templates, application packets, and postmortems.

Operating rule:
Conversation creates the idea. GitHub records the structure. Tests verify the structure. Issues track the work. Pull requests merge durable progress. Submissions use versioned artifacts. Results feed back into the architecture.

Current seriousness rule:
This is a real working system. Fun is allowed, but claims require proof.

Current anti-drift rule:
No important system component should exist only as a chat message or zip file. It must be moved into the repo or explicitly marked as temporary.

Current proof rule:
No win, score, bounty, or competition-readiness claim is valid without a linked proof artifact: dataset, command, version/hash, timestamp, result file, and limitation statement.
