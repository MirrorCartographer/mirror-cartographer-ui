## Hosting/testing gate

Vercel remains useful as the fastest public host, but it is not fully reliable because the latest inspected Vercel status showed a build-rate-limit failure. Keep Vercel for now, but do not treat it as the only proof surface.

Cloudflare Pages or Netlify would improve workflow if Vercel rate limiting persists. GitHub Pages may work for a static Vite build but would require explicit Pages setup and routing validation.

A separate stable repo is not needed yet because a rollback branch already exists. A stable branch/tag plus live smoke is enough for the current maturity level.
