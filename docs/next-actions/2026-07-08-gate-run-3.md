Attempted smallest safe implementation:

- Update `.github/workflows/smoke.yml` to use `npm install` and remove npm cache dependence until a lockfile exists.

Result:

- Direct workflow write was blocked by the current tool/write filter.

## Decision

Do not add Composition Clock, new sound voices, weather coupling, visuals, or additional interaction layers until the test gate can actually execute.

## Hosting/testing gate

Vercel remains suitable as the primary host. The problem is still not hosting capacity; it is verification reliability.

Cloudflare Pages remains the best parallel preview candidate only if Vercel previews become unreliable or if branch-preview testing becomes easier there.

Netlify is acceptable but not enough stronger to justify migration.

GitHub Pages remains weak as primary hosting for this app because the project needs fast preview iteration and low-friction rollback.

A separate stable repo is premature. A stable branch is better once the smoke workflow is passing.
