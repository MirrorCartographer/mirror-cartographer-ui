## Hosting/testing assessment

Vercel is still the correct primary host for the private phone-first weather/music prototype when builds are available: it is already connected and gives the fastest normal GitHub-to-preview loop.

However, the latest commit status reported Vercel failure with a build-rate-limit upgrade target. That is now a real preview reliability issue, not just a theoretical one.

Cloudflare Pages is now the strongest fallback path for preview reliability because it can provide a second deployment lane when Vercel build quota is exhausted. It should be wired for this private repo if tool/user access allows.

Netlify remains acceptable for Vite static hosting, but does not beat Cloudflare for the immediate second-lane strategy.

GitHub Pages remains weaker for this app because branch-preview ergonomics and rollback/testing loops are less direct.

A different repository is not recommended for the phone-weather app right now. This private repo remains the correct source of truth. Use a stable branch later, once the CI gate is visibly passing.
