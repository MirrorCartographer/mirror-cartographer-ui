## Decision

Follow the previous action partially, but keep novelty blocked.

The reliability path advanced enough to consolidate CI around the same command humans and agents should run locally. The system is not ready for new weather/music composition behavior until the latest workflow run is inspected and proven green.

## Implemented

Updated `.github/workflows/smoke.yml` so CI now runs:

- `npm install`
- `npx playwright install --with-deps chromium`
- `npm run test:gate`

This removes drift between CI and the local gate script.

## Hosting/testing gate

Vercel remains suitable for the live site because the current blocker is not hosting capacity. The higher-value change is testing discipline: local gate, CI gate, and a future live URL gate should agree before novelty resumes.

No migration to Cloudflare Pages, Netlify, GitHub Pages, or a separate stable repo is justified yet. A separate stable branch or tag is still useful once CI passes, because it creates a rollback point before the next creative system change.
