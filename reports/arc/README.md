# ARC Reports

Purpose: store proof artifacts for ARC experiments.

No ARC score claim is valid unless a report exists here or in a linked external benchmark record.

Required report fields:
- solver version or commit SHA
- dataset name and path
- command run
- timestamp
- total tasks or test items
- attempt one accuracy
- attempt two accuracy
- pass-at-two accuracy
- convergence count
- convergence correctness rate
- failure list
- limitation statement

Current status:
No real ARC public benchmark report is committed yet.
