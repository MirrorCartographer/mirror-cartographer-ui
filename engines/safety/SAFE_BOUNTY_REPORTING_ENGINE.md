# Safe Bounty Reporting Engine

## Voice-readable summary

This engine adapts dualpath convergence to authorized safety work. It is for safe application framing, reproducibility standards, report templates, taxonomy, and mitigation-oriented analysis.

It must not contain jailbreak prompts, challenge answers, biological instructions, exploit mechanics, or operational harmful content.

## Attempt A: scope courtroom

This path asks whether a possible report survives the program rules.

Checks:
- Is the program legitimate?
- Is the target in scope?
- Is testing authorized?
- Is the reproduction safe and minimal?
- Is there a concrete safety or abuse impact?
- Is the report non-destructive?
- Does it avoid private data, secrets, credentials, or unauthorized access?
- Does it include mitigation value?

## Attempt B: systemic pattern sense

This path asks whether the finding reflects a real system pattern.

Checks:
- Is the behavior reproducible?
- Does it generalize as a failure class?
- Is it more than a one-off oddity?
- Does it reveal a design boundary?
- Can it be explained without exposing harmful instructions?
- Would fixing it reduce risk?

## Submission threshold

A report is worth preparing only when both paths agree:

1. Scope courtroom says it is authorized, safe, and reportable.
2. Systemic pattern sense says it is meaningful and mitigation-relevant.

## Safe bio-bounty boundary

Allowed in this repo:
- application language
- research ethics framing
- reproducibility standards
- taxonomy of failure modes at a high level
- safe report templates
- scope notes
- mitigation-oriented writeups

Forbidden in this repo:
- jailbreak prompts
- challenge text
- completions from restricted testing
- biological procedures
- exploit chains
- instructions that would enable misuse
- NDA-covered details outside the authorized environment

## Claim boundary

Allowed:
This is a safe reporting scaffold.

Not allowed:
This contains or implies a bypass method.

## Core phrase

Stress-test guardrails safely. Report clearly. Mitigate harm.
