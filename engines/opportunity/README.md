# Opportunity Engine

Purpose: find legitimate external programs where Mirror Cartographer thinking can be adapted safely and usefully.

Program types:
- AI reasoning competitions
- safety bug bounties
- research prizes
- grants
- platform partner programs
- public-good technology challenges
- art and media fellowships

Operating rule:
The external program defines the target. Our values define allowed methods. The architecture adapts in the middle.

Scoring dimensions:
1. Legitimacy.
2. Scope fit.
3. Prize or strategic value.
4. Safety and ethics.
5. Submission burden.
6. Evidence requirements.
7. Whether ChatGPT can prepare most of the package through the control-room workflow.

Output:
Each candidate opportunity should become either rejected, watchlisted, or converted into a submission packet.
