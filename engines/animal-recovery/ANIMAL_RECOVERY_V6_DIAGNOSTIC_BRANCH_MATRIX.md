# Animal Recovery v6 Diagnostic Branch Matrix

## Voice-readable summary

This matrix converts concern into testable branches. The purpose is to help the user and veterinarian identify which branch is most likely, which branch is most treatable, and which test changes the decision fastest.

This matrix does not diagnose. It organizes questions and evidence.

## Core rule

Do not ask, "What is wrong?" as one giant question.

Ask:

1. What branches are plausible?
2. Which branches are dangerous?
3. Which branches are treatable?
4. Which low-cost test separates them?
5. What response would prove the treatment is working?

## O'Malley branch matrix: enlarged lymph nodes

| Branch | Why possible | High-value test/question | Health-upgrade possibility | Escalation trigger |
|---|---|---|---|---|
| Lymphoma or other cancer | enlarged lymph nodes can be cancer-related | lymph node FNA; biopsy if inconclusive | remission/treatment planning if confirmed | rapid growth, weight loss, low energy, poor appetite, abnormal breathing |
| FeLV/FIV-related disease | viral disease can alter immune/cancer risk | FeLV/FIV test or status confirmation | supportive care, infection prevention, treatment planning | recurrent infections, anemia, poor recovery |
| Bacterial infection | lymph nodes can enlarge from infection | CBC, temperature, FNA cytology/culture if indicated | possible cure if bacterial and treated correctly | fever, pain, pus, worsening swelling |
| Inflammatory/immune disease | immune activation can enlarge nodes | CBC/chemistry, FNA pattern, vet exam | stabilization or remission depending on cause | multi-system symptoms or worsening despite treatment |
| Fungal/systemic infection | possible depending geography/exposure | vet-guided fungal testing if signs fit | treatment possible if identified | respiratory signs, weight loss, fever, disseminated signs |

## O'Malley next best vet script

I want to know whether these lymph nodes are cancer, infection, viral/immune-related, or another treatable process. Which test changes the decision most: FNA, FeLV/FIV confirmation, CBC/chemistry/urinalysis, or something else?

## Bug / Bugsy branch matrix: heart murmur plus glaucoma/eye concern

| Branch | Why possible | High-value test/question | Health-upgrade possibility | Escalation trigger |
|---|---|---|---|---|
| Primary glaucoma/eye disease | eye pressure can damage vision | tonometry / intraocular pressure check | protect vision, reduce pain, slow damage | squinting, eye pain, cloudiness, sudden vision behavior change |
| Systemic hypertension | blood pressure can affect eyes, kidneys, heart, brain | blood pressure measurement | treatable if identified | eye changes, neurologic signs, kidney signs, sudden weakness |
| Kidney disease | can be associated with hypertension/systemic changes | chemistry, urinalysis, blood pressure | manage/stabilize; sometimes slow progression | increased thirst/urination, poor appetite, weight loss |
| Thyroid/metabolic disease | can contribute to systemic pressure/cardiac issues in cats | thyroid test if age/signs fit | treatable/manageable if confirmed | weight loss with appetite, agitation, high heart rate |
| Structural heart disease | murmur may be benign or significant | murmur grade, echo, chest imaging if indicated | treatment/monitoring depending disease | labored breathing, collapse, coughing, blue/pale gums |

## Bug / Bugsy next best vet script

Bug has a murmur and eye-pressure/glaucoma concerns. I want to protect vision and rule out systemic hypertension, kidney disease, thyroid/metabolic disease, and significant heart disease. Can we prioritize blood pressure, eye pressure, and basic bloodwork first?

## Griffey and Nimby branch matrix: facial scabs in multiple animals

| Branch | Why possible | High-value test/question | Health-upgrade possibility | Escalation trigger |
|---|---|---|---|---|
| Fleas/flea allergy | common, can affect multiple animals | flea combing; vet-approved prevention review | often treatable if controlled | spreading scabs, intense itch, multiple pets affected |
| Mites/parasites | can cause crusting/itch/scabs | skin scraping; parasite trial if vet thinks appropriate | treatable | worsening lesions, ear/face involvement, household spread |
| Ringworm/dermatophyte | contagious; can affect animals and humans | Wood's lamp, fungal culture/PCR if indicated | treatable but requires environmental control | circular hair loss, spread to people/animals |
| Bacterial infection | scabs can become infected or start from infection | cytology; culture if recurrent/severe | treatable with correct medication | pus, swelling, pain, odor, fever, lethargy |
| Allergy/environment | shared exposure can trigger both | history, response to parasite control, food/environment plan | manageable if trigger found | recurrent pattern, seasonal/environment link |
| Stress/immune vulnerability | illness/stress can worsen skin barrier | vet exam plus rule-out other causes first | supportive plus treat primary cause | poor healing, recurrent infections, other systemic signs |

## Griffey/Nimby next best vet script

Both have facial scabs, so I want to know if this is contagious, parasitic, infectious, allergic, or environmental. Can we start with flea/parasite check, skin scraping, cytology, and ringworm testing if indicated?

## Treatment-response tracking standard

For every treatment or vet recommendation, log:

- start date
- exact medicine/product/food/intervention name
- dose or application instructions as given by vet
- expected response window
- what should improve
- what would mean stop/call vet
- objective result after 24 hours, 72 hours, 1 week, and 2 weeks if appropriate

## Second-opinion trigger rules

Consider second opinion or specialist discussion if:

- diagnosis remains unclear after the first highest-value test
- symptoms worsen despite treatment
- treatment is only comfort-focused but no cause has been identified
- the animal has persistent weight loss, appetite decline, breathing changes, collapse, eye pain, rapidly growing swelling, or repeated infections
- the vet cannot explain what result would confirm or disconfirm the working diagnosis

## Claim boundary

Allowed:

This matrix helps prepare focused veterinary questions and track evidence.

Not allowed:

This matrix diagnoses or selects treatment without a veterinarian.
