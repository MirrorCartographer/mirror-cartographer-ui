# ARC Engine

Purpose: build an offline, proof-governed ARC solver and benchmark system.

Voice-readable summary:
This folder is where the ARC competition machine lives. It should contain solver code, benchmark harnesses, synthetic tests, real public-result logs, failure taxonomies, and claim registers.

Current status:
- The benchmark harness exists.
- Synthetic harness tests are added.
- Real ARC public benchmark results are not yet committed.
- No accuracy claim is valid until a result file exists under reports/arc.

Core rules:
1. No internet during solver evaluation.
2. Two official outputs, but unlimited internal search within runtime limits.
3. Two attempts must be generated by blinded independent tracks when possible.
4. Claims require proof artifacts.
5. Public evaluation must not be overused for algorithm development.

Next steps:

2. Run synthetic tests in CI.
3. Run public training benchmark locally or in Kaggle.
4. Add failure taxonomy.
5. Expand candidate generators.
