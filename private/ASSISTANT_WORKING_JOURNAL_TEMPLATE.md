# Assistant Working Journal

Status: TEMPLATE

Purpose: A repository-local working journal for tracking architectural understanding, research directions, unresolved questions, design decisions, and self-audits.

This is not a user diary. It must never contain personal data, raw conversations, health information, financial information, household information, credentials, or other private material.

Allowed:
- Architecture insights
- Design hypotheses
- Research questions
- Failure modes
- Lessons learned
- Future experiments
- Decision logs
- Knowledge gaps
- Reflections on reasoning quality

Required fields for each entry:
- Date
- Topic
- Observation
- Evidence level (Observed / Inferred / Hypothesis / Implemented / Verified)
- Confidence
- Open questions
- Next action
- Revision reason

Entries should be abstract, reproducible, and public-safe.
