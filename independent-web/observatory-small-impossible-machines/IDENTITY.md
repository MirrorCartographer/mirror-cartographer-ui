# The Observatory of Small Impossible Machines

## Premise

A self-contained browser artwork in which three abstract mechanical organisms reveal their behavior through consequence rather than instruction.

## Independence boundary

This work is deliberately not:

- a Mirror Cartographer explanation page;
- a research portal;
- a worker dashboard;
- a product funnel;
- a payment or conversion surface;
- a diagnostic, therapeutic, or medicine-facing interface.

It may share repository infrastructure temporarily, but it has its own title, visual grammar, interaction model, and future hosting target.

## Interaction grammar

1. **Rhythm machine** — responds to movement velocity.
2. **Stillness machine** — grows only when input stops.
3. **Memory machine** — retains exactly one recent gesture and replaces it on the next gesture.

## Accessibility and performance constraints

- keyboard-operable sound and reset controls;
- live textual status for consequential interactions;
- semantic description of the canvas experience;
- reduced-motion accommodation;
- no external assets, fonts, libraries, or network calls;
- device-pixel ratio capped at 2;
- one canvas and one animation loop;
- audio begins only after explicit user activation.

## Hosting rule

Do not deploy this directory through the Mirror Cartographer Vercel production project. Publish only through an independent hosting target after a separate deployment decision and evidence record.
