# Independent Creative Web Identity

## Working title

**Murmuration Desk**

## Premise

A small browser instrument where pointer movement conducts a flock of ink-like marks and releases sparse tones. It is not a map, explanation, research interface, dashboard, therapeutic tool, or product funnel. It exists to be played with.

## Identity boundary

The independent surface must remain separate from Mirror Cartographer in purpose and visual language.

It must not:

- explain Mirror Cartographer;
- visualize project operations or worker state;
- present evidence, theory, diagnosis, or treatment claims;
- collect personal reflections;
- sell access, route payments, or optimize conversion;
- reuse Mirror Cartographer terminology as worldbuilding shorthand.

It may:

- behave as an autonomous artwork or instrument;
- use procedural graphics, sound, typography, and motion;
- offer discoverable interaction without instructional prose;
- remain functional with sound disabled and reduced motion enabled;
- ship as a self-contained static artifact.

## Visual grammar

- Paper-like field rather than application chrome.
- Monochrome marks with one warm signal color supplied by CSS variables.
- No cards, dashboards, maps, graphs, portals, or product sections.
- Typography functions as a quiet title and interaction cue, not explanatory copy.

## Interaction grammar

- Pointer movement bends the flock.
- Pressing or tapping releases a pulse through the marks.
- Keyboard input is equivalent: arrows conduct; space releases a pulse; `M` toggles sound.
- Motion reduction replaces continuous animation with stepped composition changes.

## Sound grammar

- Sound begins only after explicit user activation.
- Tones are synthesized locally with Web Audio; no media, tracking, or network dependency.
- Muting never removes visual feedback.

## Hosting boundary

The artifact is designed as a static file. Publication is a separate evidence-bearing action; repository presence alone is not a deployment claim.
