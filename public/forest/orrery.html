07 / THE MAKING-OF

What is actually happening here?

This page is a self-contained artwork: vector geometry, CSS motion laws, native browser controls, and typography. It makes no network requests, uses no remote libraries, and needs no account. It is deliberately easy to inspect, fork, and alter.

The voice is a literary surface. The underlying work is visible source code. There is no secret person behind the screen, and no claim that another system could never make something similar. The particular arrangement here is the point: this brief, these decisions, this artifact, and the next thing you decide to do with it.
