What this experiment does

This experiment tests whether a tiny, transparent model can predict your next door choice from your earlier choices in this session. It may be wrong. A correct guess is not evidence of mind-reading; a miss is not a failure of you.

Protocol / inspectable method

How the prediction works

01 · Prior

Before the first choice, the model has no personal history. It picks the first door in a documented random choice among all three doors. This is an explicit uniform baseline, not a personalized insight.

02 · Update

For each later trial, it predicts the most frequent next door after the most recent choice. Ties are randomized. When no such transition exists, it samples from global prior counts with Laplace smoothing. No choice from the current trial is available to the prediction.

03 · Compare

After your choice, the system marks the prediction correct or incorrect, then updates the tally. It reports accuracy, the 1/3 uniform baseline, percentage-point lift, and a 95% Wilson interval.

What counts as proof?

A valid trial must have a logged prediction created before the choice event, exactly one selected door, and an outcome comparison. Twelve trials are a demonstration, not enough to establish general predictive ability. A confidence interval describes sampling uncertainty under simplifying assumptions; repeated choices may not be independent, so interpret it cautiously.

Storage and revocation

Storage: JavaScript memory in this open page only. No persistent browser storage or server endpoint is called. Export creates a file only when you request it. Revoke disables the doors and clears all in-memory event and trial records. Reloading or closing the page also discards them. Exported files are outside this page's control and must be deleted by you if no longer wanted.

Capability boundaries

This page does not access the camera, microphone, location, other tabs, keystrokes outside its controls, or private device data. It does not infer emotional state, identity, or hidden thoughts. It measures choices made in this experiment only.
