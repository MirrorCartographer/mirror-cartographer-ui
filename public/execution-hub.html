Proof rules

Source verified means code or a record exists.

Runtime verified requires an observed execution and preserved output.

Historical evidence can establish that a workflow was attempted without proving it succeeded.

Adoption requires a traceable connection to an OpenAI decision or implementation; similarity is not enough.
