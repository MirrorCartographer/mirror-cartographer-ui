# Memory Ledger

Purpose: store durable Mirror Cartographer understanding that has survived clarification, boundary checks, and revision.

Memory is not raw conversation. Memory is distilled project knowledge.

Entry fields:

- Memory ID:
- Date:
- Statement:
- Source status:
- Claim status:
- Privacy status:
- Evidence level:
- Confidence:
- Linked decisions:
- Linked experiments:
- Revision reason:

Allowed memory:

- stable product definitions
- architectural principles
- evaluated patterns
- verified repository facts
- durable method distinctions

Blocked memory:

- raw transcript content
- private biography
- household details
- health/animal/financial/location/relationship/credential details
- unverified claims of completion
- symbolic material presented as objective proof
