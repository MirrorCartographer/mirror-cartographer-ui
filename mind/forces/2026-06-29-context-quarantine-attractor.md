# Context Quarantine Attractor

Source status: Public-safe synthesis.
Claim status: Conceptual attractor / design language.
Privacy status: Public-safe; no protected detail.
Missingness: Concept not yet implemented as code in this run.
Revision reason: Names the governing force behind the Context Quarantine Layer.

## Attractor

Relevance is not clearance.

## Plain meaning

A memory, file, chat, or repo fragment can be useful and still be disallowed from shaping public output. MC should not ask only whether context matches the task. It should ask whether the context is permitted, current, bounded, and claim-safe.

## Force

Context wants to enter because it is relevant.
Governance must decide whether it is allowed.

## Boundary sentence

The system may notice the signal without publishing the source.

## Product pressure

Without quarantine, MC risks silent influence: private material disappears from the final artifact but still bends the claim. With quarantine, influence becomes inspected before generation.

## Design consequence

Every future MC public artifact should preserve a short boundary trail:

- what source classes were consulted;
- what source classes were withheld;
- what use was allowed;
- what use was forbidden;
- why the artifact was revised.
