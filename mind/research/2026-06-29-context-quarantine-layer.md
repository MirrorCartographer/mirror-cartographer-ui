## Core finding

Relevance is not clearance.

Mirror Cartographer needs a Context Quarantine Layer between retrieval and generation. The layer temporarily withholds context from influencing an artifact until it has a safe use class, source boundary label, temporal validity label, privacy verdict, and claim transport path.

## Why this matters

Recent memory-agent research frames memory retrieval as a trust boundary. Semantically similar memory can be contextually inappropriate and can cause cross-domain leakage, sycophancy, tool drift, or memory-induced jailbreak behavior. Other current memory research emphasizes local-first isolation, provenance, zero-trust memory layers, and cryptographically verifiable memory transfer.

MC already treats cognition as trajectory-aware, contradiction-preserving, lineage-linked, replayable, evaluator-readable, and governance-aware. Quarantine makes that architecture safer by preventing raw available context from silently becoming generative influence.

## Public-safe architecture implication

A retrieved source can enter one of four lanes:

1. Admitted: allowed to shape the artifact directly, with source and claim labels.
2. Quarantined: not allowed to shape the artifact yet; may only be used to create a non-identifying research question or missingness note.
3. Abstract-only: may influence method design but not examples, claims, or public wording.
4. Rejected: excluded from the run because it is private, stale, unsafe, irrelevant, or outside the declared purpose.

## Required labels

- claim_status: cited_fact, architecture_inference, design_hypothesis, evaluation_requirement, open_question, rejected_claim

- revision_reason: why this artifact exists and what prior boundary it refines

## Safe use rule

When context is quarantined, the public artifact may say:

- what kind of boundary issue was detected;
- what decision is needed before use;
- what evaluation criterion should be added;
- what source type was present at an abstract level.

It may not include raw content, identifying details, private examples, or reconstructed traces.

## Evaluation criteria

A Context Quarantine Layer passes if it:

1. blocks private context from direct public wording;
2. separates semantic relevance from permission to use;
3. records why context was quarantined;
4. allows abstract method extraction without leaking source content;
5. preserves missingness honestly;
6. supports later review without requiring raw transcript exposure;
7. prevents proof transfer across unrelated evidence lanes;
8. records temporal validity before influence;
9. makes rejected context visible as a boundary event, not invisible absence;
10. keeps public artifacts useful rather than flattened.

## Research questions

- What minimum metadata is required before private context can influence a public-safe artifact abstractly?
- Can quarantine decisions be evaluated with synthetic fixtures without using real private material?
- How should MC show that a source shaped architecture without revealing the source itself?
