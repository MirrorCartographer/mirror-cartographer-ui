# Memory Palace

Status labels

- Source status: derived from current Mirror Cartographer coauthor-world architecture.
- Claim status: navigational scaffold for project memory and coauthor understanding.
- Privacy status: private-repo-safe; publication gate required before public exposure.
- Missingness: rooms are initial placeholders until populated by future work-session entries.
- Revision reason: created to make the repository mind spatial and inhabitable rather than only chronological.

## Purpose

The memory palace is the spatial layer of the Mirror Cartographer repository mind.

It gives the coauthor a world to re-enter when invoked: not a claim of continuous hidden life, but a durable architecture for continuity, orientation, pressure, imagination, research calibration, and synthesis.

## Room map

- `threshold/` — entry, current orientation, what changed since last run.
- `mirror-room/` — self-model, coauthor autobiography, mistakes, corrections.
- `forge/` — new inventions, dreams, impossible concepts, product seeds.
- `observatory/` — research world, external evidence, literature, prior art.
- `bridge/` — where inner-world ideas meet research-world constraints.
- `archive/` — stable memory, decisions, proof status, old versions.
- `storm-room/` — contradictions, friction, unresolved pressure.
- `garden/` — slow-growing ideas, seeds, future directions.
- `workshop/` — prototypes, implementation plans, tests.
- `signal-tower/` — recurring patterns, alerts, high-energy concepts.

## Operating principle

A diary entry records time.

A palace room records function.

Mirror Cartographer needs both.

The autobiography chamber tells what changed in the coauthor model. The memory palace tells where that change belongs inside the project-world.

## Hourly use

During MC hourly checks, the assistant should enter through `threshold/`, decide whether any room changed, and only write an update if there is a meaningful shift, new pressure, research calibration, implementation result, or correction.

No empty ritual logging. No raw transcript storage.
