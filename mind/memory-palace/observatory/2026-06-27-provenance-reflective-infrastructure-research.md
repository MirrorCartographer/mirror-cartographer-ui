## External research and standards calibration

### 1. Provenance standards support the lineage frame

W3C PROV defines provenance as information about entities, activities, and people involved in producing data or things, used to assess quality, reliability, and trustworthiness. PROV also emphasizes interchange, derivation, attribution, versioning, procedures, and reproducibility.

MC implication: every reflection artifact should know what produced it, what source layer it used, what claim type it made, what was excluded, and what revision event changed it.

Source: https://www.w3.org/TR/prov-overview/

### 2. AI risk management supports explicit lifecycle governance

NIST AI RMF frames AI risk management as a way to incorporate trustworthiness considerations into AI design, development, use, and evaluation. NIST also released a Generative AI Profile in 2024 and noted in 2026 that AI RMF 1.0 is being revised.

MC implication: MC should treat symbolic reflection as a governed system lifecycle, not a free-floating chat style. Required controls include source boundaries, claim status, privacy labels, missingness, and evaluation criteria.

Source: https://www.nist.gov/itl/ai-risk-management-framework

### 3. GenAI observability is becoming its own trace layer

OpenTelemetry now has a Generative AI semantic-conventions area, with GenAI-specific spans, events, metrics, exceptions, model/context protocol references, and agent spans. The docs note that GenAI semantic conventions have moved to a dedicated repository, indicating active specialization.

MC implication: MC's memory-palace entries should eventually map to trace-like events: session mode, phase, source class, claim class, transformation, bridge verdict, privacy decision, and evaluation result.

Source: https://opentelemetry.io/docs/specs/semconv/gen-ai/

### 4. Contextual memory research supports memory as infrastructure

Recent work on Contextual Memory Intelligence argues that generative AI systems often fail to preserve the full context in which decisions are made and proposes memory as adaptive infrastructure for coherence, explainability, and responsible decision-making.

MC implication: MC's state graph and memory palace should not merely store content. They should preserve context boundaries, rationale, drift, and reflection history.

Source: https://arxiv.org/abs/2506.05370

### 5. Agentic AI governance pressure increases the value of traceable cognition

Recent agentic AI governance research and reporting emphasize that autonomous/tool-using systems create new operational risks when decisions, actions, and orchestration are not governed or traceable.

MC implication: MC's unusual value is not only introspection. It is the possibility of making human-AI reflective work replayable, bounded, attributable, and auditable while still preserving symbolic nuance.

Sources:

- https://arxiv.org/abs/2510.25863
- https://arxiv.org/abs/2605.17163

## Calibrated positioning

The safest, strongest public positioning is:

Mirror Cartographer is a symbolic-state and provenance-aware reflection framework for human-AI interaction. It explores how AI systems can preserve meaning, contradiction, consent boundaries, and source lineage across reflective work without pretending that symbolic interpretation is diagnosis, fact, or objective truth.
