# Observatory

Status labels

- Source status: derived from memory-palace and bridge architecture.
- Claim status: research-calibration scaffold.
- Privacy status: public-safe as abstract structure.
- Missingness: research notes require citations and separate entries.
- Revision reason: created so external evidence has its own room without becoming the origin of all MC ideas.

## Function

The observatory stores research-world material:

- papers
- prior art
- technical constraints
- evidence summaries
- contradictions
- adjacent fields
- market/product comparisons
- evaluation methods

## Rule

Research constrains and calibrates.

It does not automatically override the forge.

Each research note should state what it supports, what it contradicts, and what it cannot answer.
