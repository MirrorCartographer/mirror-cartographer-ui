# Storm Room

Status labels

- Source status: derived from memory-palace architecture.
- Claim status: contradiction and unresolved-pressure scaffold.
- Privacy status: public-safe as abstract structure.
- Missingness: specific contradiction entries are separate from this definition.
- Revision reason: created so unresolved tensions are preserved instead of prematurely resolved.

## Function

The storm room stores friction:

- contradictions
- competing explanations
- safety tensions
- authorship tensions
- claim-status conflicts
- fantasy-vs-evidence conflicts
- implementation mismatches

## Rule

Do not rush storms into synthesis.

Some contradictions are productive because they show where MC is not yet thinking clearly enough.
