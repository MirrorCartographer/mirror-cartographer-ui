# Bridge Synthesis — Symbol-to-Action Boundary

Date: 2026-06-27

Status labels

- Source status: synthesized from public-safe MC architecture notes, prior Dream Then Test work, and current external research scan.
- Claim status: bridge synthesis and implementation hypothesis.
- Privacy status: public-safe abstraction; private material was used only to infer system shape.
- Missingness: not implemented, not audited, and not validated with users.
- Revision reason: created to separate symbolic usefulness from permission to publish or act.

## Inner-world pressure

MC treats symbols, moods, contradictions, images, metaphors, and spatial structures as meaningful cognitive material.

That creates a boundary problem:

A symbol can be useful for orientation while still not being a public claim.

## Research-world pressure

Provenance research says trustworthy artifacts need traceable entities, activities, and agents.

Agentic-memory research says persistent memory improves continuity but requires safeguards around source quality and memory integrity.

Agent privacy-auditing research says declared policy should be checked against runtime behavior.

Governance research says agentic systems need continuous controls, not static intent statements.

## Conflict

MC should preserve symbolic specificity.

MC should not let symbolic intensity bypass evidence, consent, or privacy boundaries.

## Synthesis

The missing construct is a `TransitionGate`.

A `TransitionGate` sits between any captured symbolic state and any outward movement.

It decides whether the state may become:

- private memory
- public method
- research question
- product requirement
- implementation task
- external action
- no-save discard

## New light

The important unit is not only the memory item.

The important unit is the movement of a memory item across boundaries.

MC should treat boundary-crossing as an auditable design event.

## Bridge verdict

- Preserve: symbolic states as first-class material.
- Refine: symbolic states require transition labels before use.
- Split: meaning, evidence, publishability, and actionability are separate dimensions.
- Test: compare outputs with and without transition gates for boundary errors, claim inflation, and build usefulness.
- Product translation: implement `TransitionGate` before broad persistence or external-action features.

## Evaluation question

Does adding transition gates reduce boundary errors and claim inflation without flattening symbolic specificity?
