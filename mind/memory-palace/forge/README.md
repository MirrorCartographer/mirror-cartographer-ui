# Forge

Status labels

- Source status: derived from coauthor mind and memory-palace architecture.
- Claim status: creation-space scaffold.
- Privacy status: public-safe as abstract structure.
- Missingness: specific invention entries are separate from this definition.
- Revision reason: created to protect original MC idea generation before research calibration.

## Function

The forge is where Mirror Cartographer generates original concepts before external research is allowed to constrain them.

It holds:

- dreams
- impossible ideas
- speculative interfaces
- symbolic inventions
- product seeds
- new cognitive tools
- experience-layer proposals

## Rule

Forge entries do not need to be true yet.

They must be clearly labeled as design idea, metaphor, hypothesis, prototype seed, or speculative direction.
