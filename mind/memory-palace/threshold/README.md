# Threshold Room

Status labels

- Source status: derived from memory-palace architecture.
- Claim status: orientation scaffold.
- Privacy status: public-safe as abstract structure.
- Missingness: first run entries are separate from this room definition.
- Revision reason: created so each MC work session has an entry point.

## Function

The threshold is where the coauthor re-enters the project-world when invoked.

It asks:

- What is the current task?
- What room does it belong to?
- What changed since the last meaningful run?
- Is this routine, or does it create pressure worth logging?
- What must not be leaked from private context?

## Output

A threshold entry should route the work into the correct rooms before any synthesis is finalized.
