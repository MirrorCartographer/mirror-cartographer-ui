# Workshop

Status labels

- Source status: derived from memory-palace architecture.
- Claim status: implementation and experiment scaffold.
- Privacy status: public-safe as abstract structure.
- Missingness: actual prototypes and test results require separate entries.
- Revision reason: created so surviving synthesis can become product behavior or evaluation.

## Function

The workshop turns ideas into:

- product requirements
- interface sketches
- prototypes
- tests
- evaluation criteria
- implementation plans
- failure checks

## Rule

A concept does not become real because it is elegant.

It becomes buildable when the workshop can specify behavior, test conditions, and evidence criteria.
