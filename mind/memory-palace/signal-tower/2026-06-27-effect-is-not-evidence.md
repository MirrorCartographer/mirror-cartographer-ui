## Signal

Effect is not evidence.

A reflection can change orientation, produce resonance, reduce confusion, or reveal a useful symbolic pattern without proving that the pattern is externally true.

## Why it matters

Mirror Cartographer works because symbols can carry felt force.

That force must be protected from two mistakes:

- dismissal: treating symbolic effect as meaningless because it is not factual proof.
- inflation: treating symbolic effect as factual proof because it feels powerful.

## Architecture implication

MC should track effect as its own object.

Effect can update:

- salience.
- user-visible usefulness.
- motif recurrence.
- design priority.
- reflection routing.

Effect cannot update by itself:

- factual certainty.
- diagnostic status.
- public proof.
- source attribution.
- action permission.
- identity permanence.

## Confirmation test

If adding EffectBoundary improves privacy, reduces overclaiming, and keeps reflections useful, this signal should be promoted from candidate signal to core MC rule.
