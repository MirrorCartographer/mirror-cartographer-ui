## Signal

MC needs to track not only where meaning came from, but what that meaning is allowed to prove.

This is `EvidenceBoundary`.

## Pattern relation

Earlier patterns:

- StateProvenance: where did this state come from?
- TransitionGate: can this state move into action or publication?
- Bounded Resonance: what can user feedback update?
- EvidenceBoundary: what can this output count as evidence for?

Together, these define a public-safe reflective architecture.

## Why it matters

MC's value depends on strong symbolic interpretation without authority inflation.

The system should be allowed to say:

- this symbol matters.
- this pattern recurs.
- this reflection helped orientation.
- this idea should become a product hypothesis.

The system should not silently imply:

- this is objectively true.
- this proves cause.
- this is clinical, legal, financial, or public fact.
- this private state is publishable.
