## Signal

Bounded resonance.

A reflection can matter without being factual proof.

A symbol can be felt-valid without being externally verified.

A user response can improve system fit without becoming a public claim.

## Why it matters

MC needs to learn from resonance because symbolic reflection is interactional.

But it must not overlearn from resonance because emotional force can produce false certainty.

The durable pattern is:

`resonance updates salience, not truth`

## Architecture link

Bounded Resonance connects four MC structures:

- `StateProvenance`: where source and claim boundaries live.
- `TransitionGate`: where symbolic states are tested before outward action.
- `Dream Then Test`: where symbolic formation happens before evidence calibration.
- `ResonanceEvent`: where user feedback becomes bounded evidence.
