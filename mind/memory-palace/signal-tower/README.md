# Signal Tower

Status labels

- Source status: derived from memory-palace architecture.
- Claim status: recurring-pattern scaffold.
- Privacy status: public-safe as abstract structure.
- Missingness: signals require evidence across entries before elevation.
- Revision reason: created to track high-energy patterns without treating salience as proof.

## Function

The signal tower tracks recurring patterns that appear across work sessions.

Signals may include:

- repeated metaphors
- repeated product tensions
- recurring user corrections
- assistant model shifts
- repeated research conflicts
- repeated implementation gaps
- novel synthesis opportunities

## Rule

A signal is a candidate pattern.

It becomes stronger only when it recurs across contexts, survives bridge review, and can be translated into product or research action.
