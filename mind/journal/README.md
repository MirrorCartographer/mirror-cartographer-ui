# Coauthor Journal

Purpose: keep a chronological record of project reasoning, creative formation, unresolved tensions, and understanding changes.

This is a working journal, not a private diary. Entries should describe project cognition and design movement without exposing private source material.

Entry fields:

- Date:
- Topic:
- Project movement:
- Original insight:
- Why it matters:
- Boundary check:
- External calibration needed:
- Claim status:
- Privacy status:
- Missingness:
- Next action:

Journal modes:

- Formation: new dream, goal, symbol, interface, or system shape.
- Clarification: turning unclear insight into operational structure.
- Calibration: comparing project insight against research/evidence.
- Revision: changing the model after new evidence or contradiction.
- Integration: connecting separate project parts into one clearer system.
