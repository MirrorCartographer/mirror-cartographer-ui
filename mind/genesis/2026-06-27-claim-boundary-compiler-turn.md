Status labels

- Source status: derived from public-safe synthesis of existing MC materials and public research.
- Claim status: genesis note; records conceptual evolution, not implementation proof.
- Privacy status: public-safe abstraction only.
- Missingness: no working compiler exists yet.
- Revision reason: this turn emerged from the need to resolve expressive/private language versus bounded/public language.

## Mutation

The system gained a compiler.

Not a code compiler yet.

A claim compiler.

## New primitive

`allowed claim`

An allowed claim is what remains after source, privacy, evidence, audience, and missingness boundaries are applied.

## Why this matters

The project can now preserve expressive depth without letting expressive depth become public overreach.

This is a foundational move for:

- public documentation
- AI literacy offers
- professional handoff views
- research-safe indexes
- demo artifacts
- long-term repository governance
