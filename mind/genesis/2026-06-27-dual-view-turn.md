## The turn

A prior question asked whether MC should have a personal private version and a professional-accessible version.

The answer became more precise:

MC should support one underlying state object with multiple consent-bounded views.

## Before

The architecture was framed as split systems:

- private engine
- public system
- care communication map
- governance/provenance lens

## After

The architecture is framed as routed derivatives:

- private meaning view
- professional handoff view
- public-safe research index
- transformation trace

## Why this belongs in Genesis

This turn changes the product grammar.

It makes consent not merely a privacy feature but a generative interface primitive.

The question is no longer only:

`What does MC know?`

The better question is:

`Which version of this meaning is allowed to exist for this audience, and what changed during translation?`
