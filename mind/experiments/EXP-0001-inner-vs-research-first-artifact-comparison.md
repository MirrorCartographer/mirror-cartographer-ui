# EXP-0001: Inner-First vs Research-First Artifact Comparison

Hypothesis tested:

HYP-0001: Inner Formation Before External Calibration.

Test type:

Evaluation rubric and artifact comparison.

Method:

Create two public-safe artifacts for the same Mirror Cartographer concept.

- Artifact A starts from inner project formation, then uses research for calibration.
- Artifact B starts from external research summary, then maps back to Mirror Cartographer.

Evaluate both artifacts against the same criteria.

Success criteria:

Artifact A should be at least as accurate as Artifact B while being more distinctive, more aligned with MC, more product-useful, and more visually/emotionally legible.

Failure criteria:

Artifact A fails if it becomes vague, overclaims novelty, ignores evidence, or cannot be implemented.

Required inputs:

- One MC concept
- One original formation note
- External calibration sources
- Evaluation rubric

Privacy boundary:

No private source details or raw transcript material.

Measurement method:

Score each artifact on:

- Novelty
- Coherence
- Product usefulness
- Evidence honesty
- Privacy safety
- Implementation readiness
- Emotional-symbolic legibility
